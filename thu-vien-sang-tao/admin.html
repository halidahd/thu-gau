Cấu Hình Google Sheets API Endpoint

Kết nối cơ sở dữ liệu đám mây Google Apps Script để mọi thiết bị đọc/ghi tập trung

* Lưu ý: URL phải có đuôi /exec và được cấp quyền "Ai có quyền truy cập: Bất kỳ ai" (Anyone).

🚀

3 Bước Kích Hoạt CSDL

  1. Tạo Google Sheet: Tạo trang tính mới tại Google Drive, đặt tên "CSDL Tu Sach So 4B".
  2. Dán mã Apps Script: Vào Tiện ích mở rộng > Apps Script. Mở file google-apps-script/Code.gs trong thư mục dự án, dán toàn bộ vào và nhấn setupDatabase rồi bấm Run.
  3. Triển khai Web App: Bấm Deploy > New deployment. Chọn kiểu Web app, mục Who has access chọn Anyone. Sao chép URL dán vào ô bên cạnh!
💡 Xem tài liệu đầy đủ tại file HUONG_DAN_CAI_DAT_API.md nằm ngay trong thư mục mã nguồn.
